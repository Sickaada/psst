# Psst

A personal macOS menu-bar app that gives Claude and Codex notifications small animated messengers. Priorities: readable notifications, predictable click/dismiss behavior, playful entrances, local-only operation, and minimal interruption.

Requires macOS 14+, a supported source app, standard notification banners and Accessibility permission. Scope excludes chat-history access, screen capture, native reply actions and guaranteed deep linking after a notification expires. Experimental banner movement is opt-in. See README for setup, privacy and release limitations.
