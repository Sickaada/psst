# Sunburst and Terminal

Original procedural Three.js models exported for Psst. Claude uses Sunburst; Codex uses Terminal. Each character has eight 64-frame entrances and a 24-frame idle cycle. Front-facing art is intentionally used from either entry direction; lettering is never mirrored. Runtime uses cached native layers and random screen-edge trajectories. See LICENSES.txt and sources.json for attribution.
