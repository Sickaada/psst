# Notification vine

User selected the climbing-vine visual and approved building/installing it. A native floating accessory on the left edge mirrors the existing unread tray. Orange leaves belong to Claude; blue leaves belong to Codex. A thin olive winding stem is the distinctive decoration; title pills remain readable and quiet. System rounded typography, cream #FFF8ED, ink #403B32, olive #748354, Claude #C87545, Codex #438CAF.

Use SwiftUI vector shapes and an AppKit nonactivating panel, not bitmap text or a webview. This scales crisply and needs no new dependency. Alternatives were a literal branching tree, constellation, mobile, transit lines and shelves; user chose vine.

Click a title to open its source app and mark read, matching the existing tray. A separate check marks read without opening. All unread items remain reachable by scrolling. Header shows count/collapse and opens tray. Collapsed badge remembers preference; empty and quiet states stay compact. Menu can hide/show vine. Existing capture, animations, app colors and startup signing stay intact. No screen recording. Use offscreen sample renders for review. Quiet mode never auto-expands it. Use the primary display visible frame and update after screen/Dock changes. Decorative transparent margins must pass mouse clicks through. Hide-text preferences apply to title and accessibility labels.
